各閾值 (Thresholds) 的設定涵義

  • 0.55 / 0.60 (較敏感)：提高毒性流警示 (toxic-flow warning) 的敏感度，但也增加假陽性撤單 (false-positive cancel)，可能過濾掉安全利潤。
  • 0.70 (較保守)：確認極度危險才撤單，保留較多做市機會，但防禦不足。

Validation Sweep：最佳參數迷思

在 Validation Set 從 0.50 掃描到 0.90，理論最佳為 0.70。
但套用於 Test Set 時 0.55/0.60 反而表現較好。

重點提醒：0.55 絕對不是可上線的閾值，它僅是測試集掃描的候選值。最佳閾值具有強烈的「狀態依賴性」。
