## 一、目前進度盤點（依實際專案內容整理）

**專案內容：** TXF L2 order book 高頻交易決策研究，延伸出 FPGA 加速線。PHC-lite（自研簡化 state-space 模型）與 hls4ml 風格的 TCN 兩條硬體路線並行，目標平台 PYNQ-Z2 (xc7z020)。

**已完成／可用成果：**
- PHC-lite seed2：csim → cosim → Vivado P&R 全流程跑通，100MHz timing met，延遲 83.16µs（`06f_phc_lite_manual_hls`）——**這是目前唯一一個端到端驗證完整的硬體結果**
- 更快版本（diagonal SSM, unroll8）：5.3µs，cosim+P&R 也驗證過，但模型訊號品質較弱、非目前採用的主模型（`06u_phc_latency_breakthrough`）
- 軟體端：HGB 模型 NEW5 一次性 holdout 為正報酬；PHC 在多組敏感度測試中排名優於 HGB、優於簡單規則

**尚未完成／缺口（依風險排序）：**
1. **完全沒有實機上板測試** — 目前所有結果都停在 P&R/cosim 模擬階段，PYNQ-Z2 只做過 wrapper 介面比對（`06r_pynq_z2_wrapper_preflight`），從未真的燒錄跑過。這是決賽現場展示的最大風險。
2. TCN/hls4ml streaming 版本：resource fit、timing met，但 **RTL cosim 從未跑完**（已定位是 harness 問題，非邏輯錯誤），代表 A3D3 特別獎要交的 hls4ml 報告目前證據力不足
3. PHC-lite 只驗證過 seed2，seed0/seed1 尚未測試穩定性（等於 0 進度，非進行中）
4. Git 沒有任何 commit 紀錄，無法做版本前後對照

## 二、決賽目標（依現況校準，非原地重寫）

**核心判斷：不是「打包資料」而已，還有 2–3 項實質工程要收尾。** 優先順序如下：

### 目標 1（最高優先）：讓 PHC-lite seed2 真的在板子上跑起來
現有 83.16µs 結果只存在模擬/報告裡。決賽評分「難易度」「設計品質」都會被現場能不能展示實機打折扣。這件事技術上已經走到 P&R 完成、只差燒錄與board bring-up，是投入產出比最高的一項。

### 目標 2：主打模型定案 — 用 seed2（83µs，已驗證）而非 5.3µs 快版本
5.3µs 版本用的是訊號品質較弱的模型，貿然主打容易被評審問倒。除非時間允許把 5.3µs 版本的模型品質也補齊，否則決賽主敘事應該圍繞 seed2。

### 目標 3：評估是否收斂 TCN cosim 以搶 A3D3 特別獎
cosim 卡住的根因已知（harness/interface 問題），理論上可修。但要誠實評估：剩下的時間夠不夠修完並跑出可信結果。如果不夠，建議明確放棄 A3D3、把資源全部押注在目標 1，避免兩頭空。

### 目標 4：交接文件更新
`NEW_TEAMMATE_BRIEFING_REPORT.md` 是現有最完整的總覽，出國前需更新到最新狀態（尤其是目標1、3的結果），讓組員在你離開後能自主判斷、不需要每件事都等你回覆。
