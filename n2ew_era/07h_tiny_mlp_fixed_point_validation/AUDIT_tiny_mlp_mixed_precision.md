# Tiny MLP Mixed-Precision Fixed-Point Audit

status: `resolved_positive`

## Purpose

This follow-up isolates two hardware-relevant changes without retraining: weights may use a narrower type than activations, and the action argmax compares the existing 40-bit accumulator logits directly instead of introducing an unnecessary output cast. Val selects the minimum passing hardware candidate; NEW3/NEW4 remain diagnostics. NEW5 was not loaded.

## Decision

The selected mixed-precision contract clears the software fixed-point gate and is ready for an independent manual-HLS CSim implementation. This is not yet evidence that Vitis maps every multiply to one DSP, meets timing, or preserves the emulator exactly; those claims require csim/csynth/cosim/P&R.
