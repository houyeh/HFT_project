# Allowed Claims

Allowed claims for the `n2ew_era` research line:

- We evaluate L2 quote-control policies under sequential proxy assumptions.
- We test whether imbalance regimes improve short-horizon proxy PnL.
- The HLS component implements a quote-control primitive.
- The experiments use validation-only selection and frozen test/OOS evaluation.
- Terminal quote EV is a diagnostic markout, not the main objective.
- The work is a research proxy for quote-control logic, not a real exchange replay.
