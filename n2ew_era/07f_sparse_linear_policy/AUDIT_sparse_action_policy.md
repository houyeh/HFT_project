# Sparse Direct-Action Policy Audit

status: `mixed`

## Method

This addendum addresses the score-regression objective mismatch by fitting the frozen PHC buy/sell/hold decisions directly with L1 multinomial logistic regression. Candidate feature sets are `['base', 'interaction']` and the fixed C grid is `[0.0003, 0.001, 0.003, 0.01]`. Training uses the train split with the same train-only boundary weights as the score experiment (scale `6.1128798`); val selects one candidate, while NEW3/NEW4 remain post-selection diagnostics. NEW5 was not loaded.

## Champion formula

For each class, compute `intercept + sum(coefficient * term)` and select the class with the largest value. Action IDs are `0=no_quote`, `1=bid`, and `2=ask`. Coefficients are folded back into the original feature basis.

## Decision

The direct-action model does not clear the strict 80%-of-PHC retention gate. However, five unique terms beat the tuned static rule on val and NEW3 under the canonical simulator, and on all three splits under session-reset evaluation. It is therefore a mixed latency-value Pareto candidate: a minimal fixed-point/HLS feasibility test is defensible only if roughly 49-68% PHC-PnL retention is acceptable.
