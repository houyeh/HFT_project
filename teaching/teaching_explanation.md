# teaching_explanation

## Purpose

This folder is the learning notebook of the project.
It explains the concepts behind the code in a teaching-oriented way.

## What It Contains

- HFT basics
- dimensionless feature ideas
- sliding windows and tensors
- TCN architecture
- walk-forward validation
- INT8 and PTQ ideas
- latency proof framing
- CME adapter notes
- C++ to HLS mainline explanation
- Vitis HLS step-by-step notes

## Best Use

If you forget why a certain code module exists, this folder is the best place to rebuild the concept before reading the implementation again.
